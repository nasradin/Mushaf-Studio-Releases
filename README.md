## ✨ مميزات التطبيق

**القراءة والتلاوة**
- قارئ مصحف بالنص العثماني وخطوط قرآنية، مع تفسير وترجمة وبحث وتكبير مريح ووضع ليلي
- الاستماع للشيوخ حسب اختيارك وبرواياتهم، مع إمكانية تحميل السور للاستماع دون إنترنت
- مشغل صوتي متكامل يعمل في الخلفية مع تحكم من شاشة القفل، وتكرار للسورة أو الآيات، وسرعة تشغيل، ومؤقت نوم

**العبادات اليومية**
- مواقيت صلاة تُحسب تلقائيًا حسب موقعك، مع إشعارات الأذان والإقامة ووضع صامت تلقائي وقت الصلاة
- اتجاه القبلة بالبوصلة
- عدّاد تسبيح، وحصن المسلم، وتذكير بأذكار الصباح والمساء

**الحفظ والمكتبة**
- تتبع الختمة وعلامات متابعة القراءة من حيث توقفت
- اختبارات حفظ تفاعلية
- مكتبة إسلامية: كتب PDF في الحديث والفقه تُضاف من جهازك

**راحة الاستخدام**
- ثيمات داكن فاخر بلمسة ذهبية وفاتح وتلقائي، وخلفيات مخصصة
- تكبير خط الواجهة لضعاف البصر
- وضع سيارة بأزرار ضخمة وتباين عالٍ للاستخدام الآمن أثناء القيادة
